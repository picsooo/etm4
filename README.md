# ETM Car-Solution — Proposition C, version claire

Exactement la même structure et le même contenu que la proposition C (version sombre).
Seule la palette change — c'est une variante à comparer, pas une nouvelle maquette.

## Ce qui reste sombre volontairement
- **L'accueil** : la photo a besoin d'un voile sombre pour que le texte reste lisible. C'est ce que font
  tous les sites clairs du secteur.
- **Le simulateur de gains** : posé sur la photo, il ressort comme un outil. En clair sur clair, il disparaîtrait.
- **Le pied de page** : ferme la page et fait ressortir le logo.

## Ce qui change
- Fond blanc, texte `#14171C`, sections alternées en gris très clair `#F4F5F7`.
- Or assombri à `#A8811A` pour le texte et les liens : le `#C9A227` d'origine ne passe pas le contraste
  minimum sur blanc. L'or clair reste sur les boutons et les icônes.
- Les cartes passent de « fond plus clair que la page » à « blanc + bordure + ombre douce ».

## Le reste
Voir le README de la version sombre : chiffres du simulateur à faire valider, horaires à confirmer,
aucun avis client inventé, photos de démonstration à remplacer.

Déploiement : GitHub → Vercel → preset **Other** → Deploy.
